      ¿Cómo actualizo esta ficha?
      

        
Esta ficha vive en un repositorio de GitHub llamado Movimientos-de-caja, publicado con GitHub Pages. Para actualizarla con una versión nueva del archivo:

        
    
          
  1. Entrá a tu repositorio Movimientos-de-caja en github.com.
    2. 
          
  2. Tocá el archivo index.html existente.
    3. 
          
  3. Usá el ícono de editar (lápiz) o "Add file → Upload files" para reemplazarlo por la versión nueva.
    4. 
          
  4. Confirmá el cambio (commit). GitHub Pages se actualiza solo, normalmente en menos de un minuto.
    5. 
        

        
Los datos que ya cargaste no se pierden: viven en el navegador de tu teléfono, atados a esta dirección web, no al archivo en sí.

        
Si después de actualizar seguís viendo la versión vieja: cerrá la app del todo (no solo minimizarla) y volvé a abrirla, o entrá una vez desde Safari directo a la URL para forzar la descarga de lo nuevo.
